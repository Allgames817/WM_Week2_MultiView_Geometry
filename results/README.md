# 实验记录

`Week2_Day1`–`Week2_Day7/outputs/` 是本地实验的轻量历史记录，收录原始 JSON、CSV、日志及小型诊断数组；原实验记录保持原字节。代表图见 [figures](../figures/README.md)。

完整运行源码、源码快照、原始图片、数据库和大型重建文件没有收录于此精简版。历史记录中的文件路径与源码哈希用于追溯当时输入，不表示仓库包含这些本地文件。

[source_manifest.json](source_manifest.json) 列出本精简版保留的原文件映射、大小和 SHA-256。[excluded_files.json](excluded_files.json) 是最初整理的历史排除清单。

修正路径后的历史证据索引见 [archive_index](archive_index/evidence_index.md)，七天源码的历史重新检查结果见 [PACKAGE_CHECKS](PACKAGE_CHECKS.md)。这些记录用于审阅已完成的实验，不是可直接执行的复现包。

原资料出处与数据说明收录于 `source_notes/`，入口见根目录 [SOURCES](../SOURCES.md)。
