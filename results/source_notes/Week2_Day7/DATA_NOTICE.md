# 数据与输出边界

本包不附原图、点云、模型权重或已运行的结果。没有下载动作，也没有修改 Day1–6 的动作。

- 证据工具只读取 `configs/evidence.json` 明确选择的 JSON 文件。
- 射线桥接只使用你实际保存的 Day6 `fuse` 结果和该次运行记录对应的原始 RGB-D 帧。
- 读取原始 LOG 时按已核对的五帧样例顺序与 metadata 关联，不把一般任意轨迹当成同一格式。
- 原图/深度/内参/LOG 的 SHA256 必须对应 Day6 provenance。移动数据可以显式改路径，但不能静默替换数据。
- 本日继承 Day6 实际的深度比例和阈值，不导入当前可能已修改的 Day5 配置来改变旧实验含义。
- PLY体素点没有原始像素身份，不作为本日的点对照输入。使用 `fused_raw_world.npz` 的 frame_id + pixel_id。
- 点云文件可能较大，程序会在本机读取保存的NPZ；绘图和接口验证只使用确定性的单帧子样本。

所有输出仅写入 Day7/outputs 的新子目录。已有目录报错；没有 `--overwrite` 或静默覆盖。

本地绝对路径、源码与输入哈希会进入 provenance 和证据索引。向公开仓库上传前检查个人路径信息。
本包及其输出不会自动上传到外部服务。
